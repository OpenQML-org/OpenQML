# Changelog

## 0.1.0

- Installable Python SDK with a NumPy-only core and top-level `import openqml` API.
- Exact dense/sparse circuit simulation, measurement feedback, small-register
  density channels, partial traces, entropy, and explicit resource budgets.
- Circuit composition, inversion, custom unitary gates, QFT, GHZ, Grover, VQE,
  QAOA MaxCut, Pauli Hamiltonians, and hybrid optimizers.
- Quantum fidelity kernels, kernel ridge classification, variational classifiers
  and regressors, gate-wise loss gradients, and classical baselines.
- Offline seeded datasets, local tasks/suites, and provenance-rich benchmarks.
- Strict OpenQASM 2 exchange, optional Qiskit conversion, and CLI examples.
- Numerical reference tests and Python/NumPy compatibility CI.
