# Code of conduct

Participants should communicate respectfully, discuss technical claims using
evidence, acknowledge uncertainty and keep criticism focused on the work.
Harassment, threats, discriminatory abuse, unwanted sexual attention and
publishing another person's private information are unacceptable.

This applies to repository issues, pull requests, discussions and project
interactions in which someone represents OpenQML. Maintainers may edit or
remove inappropriate content, restrict participation or escalate to repository
administrators. The response should reflect the conduct and its impact.

Report concerns privately through a maintainer's publicly listed contact method.
If no private channel is listed, request one without posting incident details
or personal information. Maintainers should limit disclosure to what is needed
to address the report and avoid involving anyone with a conflict of interest.
Project roles and decision procedures are described in
[GOVERNANCE.md](GOVERNANCE.md).
